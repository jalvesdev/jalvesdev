Boa parte dos meus projetos começa com uma necessidade real, uma ideia que quero experimentar ou algum problema que acredito que possa resolver de uma forma melhor.

Alguns dos projetos que você encontrará por aqui:

Uma extensão de navegador criada para controlar a velocidade de reprodução de vídeos usando atalhos simples de teclado.

O projeto começou como uma ferramenta para uso pessoal e também se tornou uma forma de explorar JavaScript puro, APIs do navegador e compatibilidade entre diferentes players de vídeo.
